# x68k

X68000 / X68000 Z まわりのハックを置くリポジトリ。トピックごとにディレクトリを分ける。

| ディレクトリ | 中身 |
|---|---|
| [x68kcli](x68kcli) | Human68k 3.02 + zsh / vim / GNU ツールの HDD イメージを作る。SLIP ドライバ (slip.sys / slipd.x)、rcmd.x、Pico W の遠隔キーボード (src/picokbd) など |
| [x68kzremotedrv-netpipe](x68kzremotedrv-netpipe) | [x68kzremotedrv](https://github.com/yunkya2/x68kzremotedrv) に、SCSI ID 6 越しに SLIP を運ぶ netpipe を足すパッチ (Wi-Fi で TCP/IP) |
| [docs](docs) | GitHub Pages (記事)。下書きは `docs/_drafts/` |

各ディレクトリのライセンスや取得物の扱いは、それぞれの README に従う。
